Prompt injection scan

Before you hand a page, an email or an issue thread to an agent, see what is in it that you would not see by reading it. Hidden elements, invisible characters, and language written to be obeyed rather than read.

Nothing is uploaded. The scan runs in this page.

Certain — this content is here and you cannot see it

    Weaker signal — language that reads like an instruction

    Pattern matching, not judgement. Ordinary writing sets these off, and a careful attacker avoids all of them.

      What this cannot tell you.
      • Whether the content is an attack. There is no reliable detector for adversarial language — a careful injection that avoids hidden elements and stock phrasing will look clean here.
      • A clean result is not permission to trust something. It means these specific mechanical tricks were absent, nothing more.
      • A site can serve your agent different content than it served you — different user agent, address, session or time. Scanning what you were given does not tell you what it will be given.
      • Pasted HTML is not executed, so anything a page builds with JavaScript after loading will not appear here. Copy from the browser's inspector rather than View Source to catch it.
