        What this cannot tell you.
        
      
          
    • Sorting follows this device's language settings, so accented letters and non-Latin scripts order the way your system orders them. Another machine can disagree, and none of it matches a byte-for-byte sort.
      • 
          
    • Case conversion is mechanical. It does not know that "iOS" or "McDonald" are spelled the way they are, and Title Case will flatten them.
      • 
          
    • Counting characters counts what Unicode calls code points. An emoji built from several joined together counts as more than one, because that is what it is.
