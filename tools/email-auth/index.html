Email spoofability

If a stranger sent mail claiming to be from this domain, would an inbox reject it? Reads the domain's SPF, DKIM and DMARC records and says what they actually enforce.

Reads public DNS records. No account, no key, nothing stored.

    What this cannot tell you.
    • DKIM selectors cannot be listed from DNS. This probes common ones, so "none found" means these names were absent — not that DKIM is unused.
    • A strict policy is what the domain asks for. Whether a receiving server honours it is up to that server.
    • This says nothing about whether a specific message was genuine. It describes the domain's policy, not a message.
