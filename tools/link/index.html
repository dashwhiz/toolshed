    • It cannot follow the link. A shortener like bit.ly, or any server-side redirect, hides its destination behind a request this page is not allowed to make — so the final address may still be somewhere else entirely.

    • Some wrappers, Mimecast among them, replace the address with an opaque identifier. There is nothing in the link left to decode.

    • A clean, plainly spelled link to a real domain can still be a scam. This describes the address, not the site behind it.
