    What this cannot tell you.
    • A matching hash is not proof of safety. It proves the bytes match the digest you were given. If that digest came from the same place as the file, both could have been replaced together.
    • SHA-1 is broken for anything security-related. Two different files can be made to share a SHA-1 digest, and this has been done in practice. It is here because old systems still print it, not because it should be trusted.
    • None of these are password hashes. They are built to be fast, which is exactly wrong for a password — that needs bcrypt, scrypt or Argon2, with a salt.
