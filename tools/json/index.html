        What this cannot tell you.
        
      
          
    • Repair is a best guess. When a value is unquoted, its end has to be inferred — a bare value containing a comma or a brace will be split in the wrong place. Valid JSON is always parsed exactly; only broken input is guessed at.
      • 
          
    • A duplicate key cannot be kept. JSON has no way to express two, so the last one wins, exactly as every parser does. The warning is there because the earlier value is gone silently otherwise.
      • 
          
    • Formatting says nothing about whether the data is correct, only that it parses.
