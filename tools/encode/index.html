        What this cannot tell you.
        
      
          
    • Encoding is not encryption. Base64 hides nothing. Anyone holding the encoded text holds the original, which is worth remembering given how often credentials travel this way.
      • 
          
    • Decoded bytes are only shown as text when they are valid UTF-8. When they are not, you get the size and the likely file type instead — printing them as text would show you something the bytes do not say.
      • 
          
    • HTML entity decoding covers named, decimal and hexadecimal entities. It does not interpret surrounding markup, so a literal tag in the input is left exactly as it was found.
