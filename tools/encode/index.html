        What this cannot tell you.
        
      
          
    • Encoding is not encryption. Base64 hides nothing. Anyone holding the encoded text holds the original, which is worth remembering given how often credentials travel this way.
      • 
          
    • Decoded bytes are only shown as text when they are valid UTF-8. When they are not, you get the size and the likely file type instead — printing them as text would show you something the bytes do not say.
      • 
          
    • HTML entity decoding covers named, decimal and hexadecimal entities, and follows the HTML rules rather than plain Unicode: &#128; is a euro sign, and a code point that cannot exist comes back as a replacement character. It does not interpret surrounding markup, so a literal tag is left exactly as found, and an entity written without its closing semicolon is left alone even though a browser would decode it.
      • 
          
    • Decoding accepts both base64 alphabets whichever option is chosen, so text using - and _ decodes either way. The choice only changes what encoding produces.
