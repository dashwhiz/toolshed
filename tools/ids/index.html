ID generator

Identifiers drawn from the browser's cryptographic random source, in bulk. The kind of thing it is tempting to ask a chatbot for — but a model writes something that looks like a UUID, and looking random is not the same as being random.

Generated in this page from crypto.getRandomValues. Nothing is uploaded.

    • Random is not the same as secret. These are fine as identifiers. Using one as an unguessable link is a different job, and the sortable formats have noticeably less randomness in them than a UUID v4 or a nanoid — the figure below says how much.

    • Time-ordered formats carry the moment they were made, in the clear. Anyone holding one knows when it was created, to the millisecond.

    • The randomness comes from this browser. If the browser's generator is weak or the device's entropy is poor, nothing on this page would show it.
