        What this cannot tell you.
        
      
          
    • Whether the token is genuine. Decoding and verifying are different things. The signature can only be checked with the issuer's key, which this page does not have and should never be given. Anyone can write a token that decodes perfectly.
      • 
          
    • Whether the server still accepts it. A token inside its time window can already have been revoked, and the clock compared against here is your own device's.
      • 
          
    • The payload is not secret. Base64 is encoding, not encryption — everything shown here is readable by anyone holding the token, which is why a JWT should never carry anything you would mind seeing.
