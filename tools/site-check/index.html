Website trust check

How old is the domain, who registered it, where does it run, and can it send mail? The signals that give away a site thrown up last week.

Uses public registration and DNS data. No account, no key, nothing stored.

    What this cannot tell you.
    • Nothing about the page itself — content, malware and reputation need a backend this deliberately does not have.
    • An old domain can still be a scam, and a legitimate site can be compromised.
    • Plenty of honest sites are new, hide their registrant, or take no mail. Read the signals, don’t count them.
